Monter un domaine Active Directory2026

Windows Server 2022, AD DS, DNS, DHCP, GPO, VirtualBox

Contexte
TP en maquette virtuelle : simuler le réseau d'une petite entreprise.
Objectif
Centraliser les comptes, les noms et les adresses IP.
Ce que j'ai fait
  • Installation de Windows Server dans une machine virtuelle.
  • Création du domaine, des unités d'organisation, des utilisateurs et des groupes.
  • Configuration du DNS et du DHCP.
  • Création de stratégies de groupe (fond d'écran, lecteur réseau, restrictions).
  • Jonction d'un poste client et tests de connexion.
Résultat
Le poste client ouvre une session sur le domaine et reçoit ses paramètres tout seul.
