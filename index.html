En formation

2026

Déploiement d'un domaine Active Directory
  • Windows Server
  • AD DS
  • DNS
  • DHCP
  • GPO
Contexte
Mise en place d'une infrastructure d'entreprise fictive en maquette virtuelle.
Objectifs
Centraliser les comptes, les noms et les adresses IP d'un petit réseau.
Ce que j'ai fait
  • Installation de Windows Server dans une machine virtuelle.
  • Création du domaine, des unités d'organisation, des utilisateurs et des groupes.
  • Configuration du DNS et du DHCP.
  • Création de stratégies de groupe (GPO) : fond d'écran, lecteur réseau, restrictions.
  • Jonction d'un poste client au domaine et tests.
Outils
VirtualBox ou VMware, Windows Server 2022, Windows 11.
Résultat
Un poste client s'authentifie sur le domaine et reçoit ses paramètres automatiquement.
